# branding

チャンネルのブランディング素材（チャンネルアイコン等）を管理するディレクトリ。

## マスターファイル

`channel_icon_master.svg` がマスター。PNG は全てこの SVG から生成される派生物であり、
**PNG ファイルを直接編集しないこと**。修正は必ず SVG 側で行う。

## 再生成

SVG を変更したら、以下のコマンドで PNG を再生成する。

```
npm run render
```

初回セットアップ時は `npm install` を先に実行すること。

## 出力サイズ

| ファイル | サイズ | 用途 |
|---|---|---|
| `channel_icon_800.png` | 800×800px | YouTube アップロード用 |
| `channel_icon_176.png` | 176×176px | 中間サイズ確認用 |
| `channel_icon_48.png` | 48×48px | 実際の小サイズ表示相当 |
| `channel_icon_48_zoom.png` | 288×288px（NEAREST拡大） | 48px版の視認性を目視確認するための拡大版 |

## 配色定義

| 用途 | カラーコード |
|---|---|
| 背景 | `#1E2B42` |
| 家 | `#F2E8D5` |
| 灯りの窓 | `#EF9F27` |

## 家のモチーフ仕様

- 二軒並びの家（左右で構成が非対称）
- 矩形の煙突を左右それぞれに配置（左右で位置が非対称）
- 片方は格子窓（消灯：背景色でくり抜き、格子は家と同色）
- もう片方はベタ塗りの窓（点灯：灯りの窓色 `#EF9F27`）

## 編集時の注意

SVG を変更したら必ず `npm run render` を実行し、`channel_icon_48_zoom.png` で
48px サイズでの視認性を確認すること。小サイズでは細部が潰れやすいため、
実際の表示サイズでの見え方を都度チェックする。
