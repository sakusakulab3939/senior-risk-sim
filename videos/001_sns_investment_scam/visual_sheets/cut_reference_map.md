# CUT参照画像対応表（001_sns_investment_scam）

`FINAL_SCRIPT_FULL.md` の各SCENE/CUTのプロンプト本文を読み、`blueprint.json` の
`visual_cast`（P1藤田健一／P2美和子）・`locations`（LOC01自宅リビング／LOC02銀行窓口）の
`locked_prompt_fragment`（またはその特徴語）が含まれているかで判定した対応表。

nanobananaで各CUTを生成する際、どのキャラクター/ロケーションシートPNGを参照画像として
添付すべきかの作業チェックリストとして使う。

判定方法：プロンプト本文の記述のみを根拠にする（NARRATIONの文脈は参照しない）。
そのため、プロンプト側に背景描写がないカットは「判定不可」としている。

## 自己チェック

- 全11 SCENE（001〜011）を漏れなく分類済み（`## SCENE` 見出し数: 11 = 表の scene_id 種類数と一致）
- 全17カット（`CUT n:` 7件 + `IMAGE_PROMPT:` 10件）を漏れなく分類済み（表の行数 = 17）
- 判定できないケースを2種類に分けて明示：
  - プロンプト本文に場所描写が無い（SCENE 004, 005）
  - プロンプト冒頭にP1特徴語はあるが人物が描かれない象徴カット（SCENE 001 CUT 6）
- **トレイトロックドリフトの修正**：`locked_prompt_fragment` との完全一致を機械的にチェックした結果、
  SCENE 004・005・006（P1）・006（P2）・007・008 のIMAGE_PROMPTでP1/P2の描写が
  `locked_prompt_fragment` から軽微にドリフトしていた（"average build" の欠落、
  "with X and Y" 表記への変化）。`FINAL_SCRIPT_FULL.md` 側を修正し、該当箇所を
  `locked_prompt_fragment` と一言一句完全一致する文字列に置換済み（演技・照明・
  ゾーングレーディング等の他要素は無変更）。修正後の再チェックでドリフトはSCENE 010を
  除き解消したことを確認した
- **SCENE 010は意図的に現状維持**：解説パート（explanationゾーン）の概念図（過信バイアスの
  象徴イラスト、"a human head silhouette with a concealed blind spot" ＋
  "an elderly Japanese man"）であり、物語内でP1本人が行動するカットではないため、
  一般化された人物のまま `locked_prompt_fragment` を適用しない方針とする（ユーザー確認済み）。
  トレイトロックドリフトの修正対象からは除外する
- SCENE 007 に `visual_cast` 未登録の脇役（銀行員）が登場することを確認した。単発の
  端役でシート化の必要性は低いと判断したが、今後同種の脇役が繰り返し登場する場合は
  `visual_cast` への追加を検討する
