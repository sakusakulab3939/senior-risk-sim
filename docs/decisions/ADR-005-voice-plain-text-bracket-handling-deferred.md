# ADR-005: voice_plain_text.txtの鍵括弧処理を保留

## 背景
`production_extractor.py` の `write_voice_plain_text` を拡張し、`voice_plain_text.txt`
生成時に数字・記号の全角化を行うこととした。あわせて、NARRATION本文に頻出する鍵括弧
「」（セリフ・引用の囲み）をVrewでの読み上げ用テキストからどう扱うかが論点になった。
ElevenLabs/Vrewでの実際の読み上げ挙動はまだ確認していない。

## 決定
鍵括弧「」は除去せず、そのまま残す。

## 捨てた選択肢と理由
- **鍵括弧を機械的に除去する**：見た目のノイズは減るが、実際に音声合成が「かぎかっこ」と
  読み上げてしまう問題が起きるかどうかを未確認のまま先回りして加工することになり、
  根拠のない対処になる。まずは残した状態で運用し、Vrewでの読み上げ確認（今後実施予定）で
  実際に問題が出た場合にのみ、次回作以降で除去ルールを追加する。
