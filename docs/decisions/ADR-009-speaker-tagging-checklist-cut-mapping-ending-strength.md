# ADR-009: 話者明示・チェックリストのカット対応・エンディングの締めの強化（次回作への申し送り）

## 背景
001（SNS型投資詐欺）の音声生成工程を終えて、以下4点の課題が判明した。

1. `voice_speaker_breakdown.md` の出力では、セリフ本文に「」がそのまま
   残っている。話者ラベル（`[健一セリフ]`等）が既に話者を示しているため、
   「」は音声制作の実務上は冗長だった。001では音声生成時に人力で「」を
   除去しながら進めたため、001の当該ファイル自体への修正は不要。
2. セリフかナレーションかの判断が曖昧な箇所があり、001では生成済みの
   画像を見て「画面に人物が登場していればセリフ」と判断して対応した。
   これはADR-006で申し送り済みの「台本執筆時点での話者明示」の必要性を、
   実体験で裏付ける結果となった。
3. checklistゾーン（SCENE 011）の教訓は5つ列挙されているが、画像は
   2カットしかなく、教訓と画像が対応していない。1教訓＝1カット
   （計5カット）にする方が、視聴者が画像とともに教訓を追えるように
   なる。
4. 台本の締め（チェックリスト後の結び）が「どこかに書き留めておいて
   ほしい」で終わっており、視聴者自身への効用（「そうすれば、あなたに
   同じことが起きた時に～」等）がもう一段階欲しい。エンディングの
   強度を上げる余地がある。

## 決定
本ADRでは実装は行わない。次回作（2本目）のB-2執筆プロンプト設計時に
参照する申し送り事項として、以下4点を記録するのみとする。

1. `voice_speaker_breakdown.md` の出力フォーマットから「」を除去する
   （`production_extractor.py` の `extract_dialogue_breakdown` を修正する）。
   001は人力対応済みのため、コード修正自体は次回作着手前に行えばよい。
2. `write_full_script.md` の出力契約に、セリフには話者を明示するタグを
   追加することを検討する（ADR-006で申し送り済みの内容を、次回作を
   候補として正式に実装するタイミングとする）。
3. `genres/risk_sim.json` のchecklistゾーンのシーン分割ルールに、
   「教訓の数とカット数を対応させる」という指針を追加することを
   検討する。
4. `write_full_script.md` のchecklistゾーンの執筆指示に、「教訓の列挙で
   終わらせず、視聴者自身への効用を示す一文で結ぶ」という指針を追加する
   ことを検討する。

## 捨てた選択肢と理由
- **001の時点で即座に修正する**：001はすでに音声生成工程まで完了しており、
  当該動画の仕様やファイルを遡って変更する実益がないため見送り、次回作
  以降の設計変更として扱う。

## 今後の検討事項（次回作への申し送り）
上記4点は次回作（2本目）のB-2設計時に参照し、実際の仕様変更
（`production_extractor.py` の `extract_dialogue_breakdown` 修正、
`write_full_script.md` の出力契約・執筆指示追加、`genres/risk_sim.json`
のchecklistゾーン分割ルール追加）は別途の意思決定に委ねる。
