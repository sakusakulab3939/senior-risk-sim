# ADR-007: 解説パート図解の具体性とエンディングカットの表現多様化（次回作への申し送り）

## 背景
001（SNS型投資詐欺）の画像生成工程を終えて、以下2点の課題が判明した。

1. explanation/checklistゾーンのCUTプロンプトでは、`text_exclusion_guard` の
   影響で「文字化けを避ける」ことを優先し、グラフ・数字・条文などを意図的に
   抽象的な表現（plain placeholder bars等）で描かせていた。実際に生成した結果、
   解説パート後半の画像が抽象的で分かりにくく、内容の説得力が弱くなった。
2. checklistゾーン（SCENE 011）の2カットが、いずれも似た構図の
   チェックリストインフォグラフィックとなり、動画のエンディングとして
   単調な印象になった。エンディングはチャンネル登録・次回視聴への導線として
   重要な箇所であり、情報整理よりも印象に残る絵作りを優先すべき箇所だった。

## 決定
本ADRでは実装は行わない。次回作（2本目）のB-1.5/B-2設計時に参照する
申し送り事項として、以下2点を記録するのみとする。

1. 解説パートの図解カットは、GPT Image 2（日本語・数字のレンダリング精度が
   高いモデル）の使用を検討する。`text_exclusion_guard` による抽象化を
   前提とせず、実データに基づいた具体的な図解（数字入りのグラフ、条文抜粋風の
   レイアウト等）を許容する設計に見直す。
2. checklistゾーンのCUTプロンプト作成時、同一構図（チェックボックス
   インフォグラフィック）の反復を避け、エンディングにふさわしい多様な表現
   （象徴的な締めのカット、次回予告的な要素等）を検討する。
   `visual_pacing.zone_color_grading` のchecklist定義にも、「単調な反復を
   避ける」旨の注記を追加することを検討する。

## 捨てた選択肢と理由
- **001の時点で即座に修正する**：001はすでに画像生成工程が完了しており、
  当該動画の仕様を遡って変更する実益がないため見送り、次回作以降の
  設計変更として扱う。

## 今後の検討事項（次回作への申し送り）
上記2点は次回作（2本目）のB-1.5/B-2設計時に参照し、実際の仕様変更
（`text_exclusion_guard` の運用見直し、`genres/risk_sim.json` の
`visual_pacing.zone_color_grading` への注記追加等）は別途の意思決定に委ねる。
