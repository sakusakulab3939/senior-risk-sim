# ADR-010: チャンネル所有アカウントの固定

## 背景
「となりの家の老後」（@tonari-no-rougo）の運用にあたり、チャンネルを所有する
Googleアカウントが曖昧なまま作業を進めると、AdSense申請時や収益化審査時に
取り返しのつかない事故につながるリスクがある。

## 決定
- 「となりの家の老後」（@tonari-no-rougo）の所有を仕事用Googleプロファイルに
  固定する
- 認証情報（アカウント・パスワード・2段階認証のバックアップコード）は
  パスワード管理ツールで管理し、リポジトリには置かない
- チャンネル関連の全作業は該当プロファイルでのみ実行する

## 捨てた選択肢と理由
- **個人用プロファイルでの運用**：仕事用と個人用が混在すると、
  AdSense紐付け時にどちらのアカウントで申請したか誤認するリスクがある
  ため見送った。
- **認証情報をリポジトリ内のメモ等に記載する**：Gitで管理される場所に
  機密情報を置くと漏洩リスクが生じるため、パスワード管理ツールでの
  一元管理に統一した。
