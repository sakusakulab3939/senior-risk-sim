# ADR-013: 動画タイトルとタグの設計規約

## 背景
001のB-6で確定したタイトルとタグに、モバイル表示での文字数超過と、機械生成による
非実用的なタグという2つの問題が見つかった。002以降で繰り返さないため規約として
記録する。

## 決定

### タイトル
- 冒頭に【漫画】を付与する。形式の明示によりジャンル不一致の離脱を減らし、
  フィクションであることを伝える
- タグは1つまで。【漫画】【衝撃】等の重ね付けはしない
- 【実話】【実録】は使用しない。内容はシミュレーションであり、規約上も視聴者の
  信頼上もリスクとなる
- タイトル本体は全角31文字以内を目安とする（モバイルは30文字前後で切れるため）
- 重要語（詐欺の種類等）は先頭寄りに配置する
- ダッシュ（——）等の多文字記号は使わない
- 引用句を使う場合、主人公固有の属性ではなく、視聴者自身の自己認識に対応する
  言葉を選ぶ
- 同ジャンルに頻出する定型句（「落とし穴」等）は避ける

### タグ
- タグは検索語として実際に入力されうる短い語のみとする
- blueprintのtheme / explanation_focusをそのまま流用しない。読点を含む長文は
  タグとして機能しない
- production_extractor.pyの自動生成タグは叩き台であり、B-6で人間が置き換える
  前提とする

## 捨てた選択肢と理由
- **【漫画】を付けない案**：形式が混在するジャンルであり、タイトルのみが表示される
  場面で判別できず、ジャンル不一致による早期離脱を招く
- **数字（金額・日数）を先頭に置く案**：視認性は高いが、台本の時間経過や金額と
  厳密に一致している必要があり、検証コストが上がる。001では見送った
