# ADR-012: 収益化ポリシー適合の設計制約

## 背景
YouTubeチャンネル収益化ポリシーの2025年7月・2026年7月改定により、本チャンネル
のフォーマット（失敗シミュレーション＋解説構成）に直接抵触しうる条項が
追加された。特に「デリケートなトピックに関連するAIペルソナ」「一般的、
または繰り返しの多いコンテンツ」「満足度の低い、または不快なコンテンツ」の
各条項は、収益化不可と判定されるリスクを内包している。

参照：
- https://support.google.com/youtube/answer/1311392
- https://support.google.com/youtube/answer/6162278

また、2027年2月1日よりYPP（YouTubeパートナープログラム）の新規広告収益化
基準が「登録者1,000人＋総再生時間8,000時間」に引き上げられる、という
期限のある外部制約もある。現行の4,000時間基準で申請できるのは
2027年1月31日までである。

## 決定
以下4点の設計制約を、台本設計・執筆プロンプト・演出方針に組み込む。

### 制約1：解説ゾーンの話者に専門家肩書きを与えない
「デリケートなトピックに関連するAIペルソナ」条項への対応。FP・弁護士・
税理士等の職業的肩書きを持つキャラクターが金融・法律・税務の助言を行う
構成は収益化不可の例に明記されている。解説は「助言」ではなく「制度の
説明」の構文で書く（「〜すべきです」ではなく「〜という制度があります」）。

### 制約2：出典の明示
各動画の解説内容に、公的機関の一次情報を出典として併記する。概要欄にも
URLを記載する。

### 制約3：バリエーションの確保
「一般的、または繰り返しの多いコンテンツ」条項への対応。主人公属性
（年齢帯／性別／職業／家族構成／誤判断の型）を動画ごとに分散させる。
エンディングパターンを固定しない（初期10本の想定分布：完全失敗4／
寸前回避3／小さな教訓3。感動回復は初期10本からは除外——詳細は
CLAUDE.mdの「結末パターンの扱い方」を参照）。

### 制約4：煽りと内容の乖離を避ける
「満足度の低い、または不快なコンテンツ」条項への対応。サムネイル・
タイトルの煽り強度が本編内容と乖離しないこと。物語には一貫した因果を
持たせ、衝撃演出のみに依存しない。

## 捨てた選択肢と理由
- **解説ゾーンにFP等の専門家キャラクターを登場させる演出**：説得力は
  増すが、「デリケートなトピックに関連するAIペルソナ」条項に該当する
  リスクが高いため見送った。
- **収益化リスクを許容し、通常運用のまま様子見する**：収益化剥奪は
  チャンネル運営の前提を崩す致命傷になりうるため、リスクを取らず
  設計段階で回避する方針とした。

## 実装状況
- 制約1（解説ゾーンの話者に専門家肩書きを与えない）
  → 反映済み: `genres/risk_sim.json`, `prompts/write_full_script.md`
- 制約2（出典の明示）
  → 反映済み: `genres/risk_sim.json`, `videos/_template/blueprint_template.json`,
    `src/production_extractor.py`
- 制約3（バリエーションの確保）
  → 反映済み: `genres/risk_sim.json`（`protagonist_variation_axes`）
- 制約4（煽りと内容の乖離を避ける）
  → 未反映。B-6（メタデータ整形）およびB-11（サムネ選定）工程への反映が
    必要。担当プロンプトが未整備のため保留。
