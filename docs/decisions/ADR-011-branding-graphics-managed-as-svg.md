# ADR-011: ブランディング図形はSVGで管理する

## 背景
チャンネルアイコン等のブランディング素材の作成方法を検討するにあたり、
画像生成AIによる生成を試したが、毎回サンプリングが変わるため同一形状を
再現できず、微調整（拡大・配色変更等）のたびに全体が作り直しになる
問題があった。

## 決定
- アイコン等の幾何形状は画像生成を使わずSVGで作成する
- PNGはSVGからの生成物として扱い、直接編集しない
- SVG→PNG変換には sharp（librsvg同梱）を使用する
- 再生成コマンド：`assets/branding/` で `npm run render`
- 家のモチーフ（二軒並び／矩形の煙突／格子窓と点灯窓）は
  location_sheet の住宅描写基準としても参照する

## 捨てた選択肢と理由
- **画像生成AIでの都度生成**：毎回サンプリングが変わり、同一形状の
  再現性がないため見送った。
- **自前のSVGパーサ（Pillowで図形を手描き再実装）**：`transform`属性
  （`scale`・`translate`等）に対応しておらず、SVG本体の見た目と
  出力PNGが乖離する不具合を実際に起こしたため見送った。
- **ImageMagick**：Windows標準の`convert.exe`と名前が衝突する上、
  SVGレンダリングは外部ライブラリ（librsvg等）への依存が別途必要で
  導入コストが高いため見送った。
- **resvg**：v0.48時点でWindows向けビルドの配布がなく（Linux/macOSの
  みリリースされている）、導入できなかった。

## 結果
sharpによるレンダリングパイプラインを構築し、800px/176px/48pxの
PNG生成、および48px版の視認性確認用にNEAREST拡大した288px版の出力を
実現した。SVGの`transform`（`scale(1.30)`）が意図通り反映されている
ことをバウンディングボックス測定で確認済み。
