# ADR-015: voice_speaker_breakdown.mdが再実行のたびに手動修正を失う問題

## 背景
002の作業で、SCENE 004の和彦の台詞の話者誤判定を手動修正した後、シート画像の
リネームに伴い`production_extractor.py`を再実行したところ、手動修正が機械推測
結果に上書きされて消失した。`voice_speaker_breakdown.md`は動画ルート直下に
生成されるが、`metadata_final.json`（B-6確定版）とは異なり「再生成されるたびに
上書きされる」という点で、実質的に`output/`配下のファイルと同じ性質を持っている。

## 決定
今回は該当箇所を再修正するのみとし、恒久対応は次回作以降に持ち越す。

恒久対応の選択肢として以下を検討する：

1. `voice_speaker_breakdown.md`を`metadata_final.json`と同様、人間確認後に
   `_final`等のサフィックスを持つ別ファイルとして確定保存する運用にする
2. extractor実行時、既存の`voice_speaker_breakdown.md`に人間による編集差分が
   ある場合は上書きせず警告を出す
3. ADR-006の恒久対応（blueprint.jsonからの自動導出等）が実装されれば、機械推測の
   精度自体が上がり、手動修正の必要性そのものが減る可能性がある

## 捨てた選択肢と理由
- **今回すぐに恒久対応を実装する**：002は既に該当箇所の再修正で対応済みであり、
  今この場で仕様変更するよりも、3本目以降の運用で同じ問題が繰り返し発生するか
  様子を見てから判断する方が、過剰な作り込みを避けられるため見送った
